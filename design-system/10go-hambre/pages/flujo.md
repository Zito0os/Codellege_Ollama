# 10go hambre — overrides de página (flujo principal)

Fuente: UI UX Pro Max + brief del usuario.

## Color (override obligatorio)
- **Background canvas:** `#FAA058`
- Primary CTA: `#9A3412`
- Secondary: `#C2410C`
- Accent (éxito / usar): `#047857`
- Cards: `#FFFDF9`
- Foreground: `#1C1917`
- Muted surface: `#FFE0BF`
- Border clay: `#E08940`

## UX
- Indicador de pasos siempre visible (1 herramientas → 2 refrigerador → 3 recetas)
- Un CTA primario dominante por pantalla
- Feedback de carga al generar
- Confirmación al usar receta (inventario actualizado)
- Focus trap en modal/drawer

## Estilo
Claymorphism suave: bordes gruesos, radios 20–28px, sombra interior + exterior, botones con press 200ms.
